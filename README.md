# Результат работы парсера:

Результат сохраняется в json-файл в директорию с анализируемым логом (`access.log` → `access.log.json`) 
 и содержит:
1) top_ips - топ 3 ip-адресов с наибольшим количеством запросов
2) top_longest - информация по 3-ём самым долгим запросам
3) total_stat - общая статистика с типом HTTP-запросов по количеству, отсортированному
по убыванию

По множеству лог-файлов формируется соответствующее множество json-отчётов.

# Способ запуска парсера:

python3 log_parser.py access.log            # конкретный файл с логами
python3 log_parser.py /home/user/logs/      # все log-файлы из папки
python3 log_parser.py                       # все log-файлы из текущей папки


# Схема работы:

Скрипт проходит каждый файл ровно один раз, строку за строкой. 
Каждая строка проверяется на соответствие шаблону строки логов: LINE_PATTERN:
`%h - - %t "%r" %s %b "%{Referer}" "%{User-Agent}" %d`
Из неё берутся IP-адрес, дата, метод, URL и длительность запроса в миллисекундах.

Основные модули парсера:
1) parse_line - метод строкового парсинга. Вычленяет данные на основе шаблона LINE_PATTERN.
2) collect_stats собирает статистику по одному файлу лога за один проход.
Под капотом содержит:
    ip_counts, count_ip - счётчики кол-ва запросов по ip-адресам
    total_requests - всего запросов
    method_counts - счётчик запросов по типу запроса. Если метод есть в HTTP_METHODS - считает его.
    top_requests, top_long - список самых долгих запросов
В общем, метод открывает лог и парсит строку за строкой методом parse_line.
3) find_log_files - собирает все .log-файлы в директории (если передана директория или ничего)
4) save_file - сохраняет результаты в json-файл
