# Анализатор access.log

Скрипт читает логи web-сервера и собирает по ним статистику.

## Как запускать

```bash
python3 log_parser.py access.log   # один конкретный файл
python3 log_parser.py logs/        # все .log-файлы из папки
python3 log_parser.py              # все .log-файлы из текущей папки
```

## Как работает

Скрипт проходит каждый файл ровно один раз, строку за строкой. Каждая строка
разбирается регулярным выражением по формату
`%h - - %t "%r" %s %b "%{Referer}" "%{User-Agent}" %d`, из неё берутся
IP-адрес, дата, метод, URL и длительность запроса в миллисекундах.

По каждому файлу собирается:

- общее количество запросов;
- количество запросов по HTTP-методам (GET, POST, PUT, DELETE, OPTIONS, HEAD);
- топ 3 IP-адресов, с которых сделано больше всего запросов;
- топ 3 самых долгих запроса: HTTP-метод, URL, IP, длительность и дата.

Статистика выводится в терминал и сохраняется в json-файл рядом с логом
(`access.log` → `access.log.json`). Если обработано несколько файлов,
каждый получает свой json и свой отчёт в терминале.

Полный проход по приложенному `access.log` (3 216 723 строки) занимает
несколько секунд.

## Проверка результата

Числа скрипта сверяются с консольными утилитами:

```bash
wc -l access.log                              # общее количество запросов
grep -c '"GET ' access.log                    # количество GET-запросов
awk '{print $1}' access.log | sort | uniq -c | sort -r -s -n -k 1,1 | head -3   # топ 3 IP
awk '{print $NF}' access.log | sort -n | tail -1                                 # самый долгий запрос, мс
```

На приложенном логе результаты скрипта совпадают со всеми проверками.
